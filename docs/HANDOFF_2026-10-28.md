或 Windows IPv6 路由。radio 与 awdld 的 GPL 进程边界继续保留，不直接混合源码。

### 怎样看停顿

- `dir=rx accepted` 只表示进 lwIP 队列，不保证 TCP 校验/接受；
  `dir=tx accepted` 只表示写入本地 IPC，不保证空口发出/手机收到。
- `payload` 含重复；`gap/overlap/repeat_ack` 是迹象，不是确证重传计数。
  `win_raw` 是原始窗口、`ws_offer` 是 SYN 提议，不直接当有效窗口。
- `up_read/up_written` 对应 lwIP 读出/本地 send 接受；`down_read/down_written`
  对应本地读出/lwIP send 接受。send 接受不等于对端应用已消费。
- 本机已观察“IPC 可排队、ACK 不前进、窗口非零、local_send 阻塞”；
  不能把所有停顿归因于零窗口或射频。TCP ACK 与 802.11 ACK 必须分开。
- 单调时间 `t_ms` 配合监管时间戳关联；5 s 快照不是精确恢复延迟。
  超时终止的是故障连接，不是续传；整链恢复 ≤10 s 尚未证明。
