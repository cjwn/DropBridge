DropBridge —— iPhone 隔空投送接收端（Windows，托盘常驻）
================================================================

这是什么
  双击 DropBridge.exe 后，任务栏右下角通知区域里会常驻一个小图标，
  不弹窗口，也不占任务栏按钮。iPhone 用系统自带的「隔空投送」就能把文件
  传到这台电脑，不需要在手机上装任何 App。

运行条件
  - Windows 10 / 11，64 位。
  - 一张 RTL8821CU 芯片的 USB 无线网卡（本项目验证过 0bda:c820）。
    DropBridge 只用这张网卡，不影响电脑原来的 Wi-Fi。

第一次运行
  1. 把整个 DropBridge 文件夹解压到一个可写的目录（例如 D:\DropBridge）。
     不要放进 Program Files。
  2. 插上网卡，双击 DropBridge.exe。
  3. 网卡还没装好驱动的话，程序会弹一次「用户账户控制」请求管理员权限，
     然后自动把网卡的 MI_02（Wi-Fi）接口换成 WinUSB 驱动。每台电脑只需要做
     一次，安装过程记在 data\logs\driver-install.txt。
     ★ 只处理 MI_02。MI_00（蓝牙）不碰。
     ★ 自动安装失败时，可以改用手动方式：双击 setup\Bind-WinUSB.cmd，
       按 setup\README.txt 的说明用 Zadig 绑定。
  4. 托盘出现图标后，网卡初始化约需 40–90 秒，完成后托盘会提示就绪。
  5. 第一次启动时程序会顺手打开「开机自启」，并提示一次。不需要的话可以在
     托盘菜单里关掉。

日常使用
  - 在 iPhone 的分享面板里选 DropBridge（或你自己起的设备名），发送文件。
    隔空投送的接收范围不需要特别设置。
  - 收到文件后，右下角会弹出系统通知。图片的通知上有「复制到剪贴板」按钮。
  - 文件默认存在 data\received。双击托盘图标可以直接打开这个文件夹。

托盘菜单
  状态                    后端是否在跑
  打开接收文件夹
  接收文件夹：…           改成任意文件夹（比如桌面），立即生效
  打开日志                data\logs\<会话>
  复制诊断信息            把运行摘要复制到剪贴板，反馈问题时贴上
  开机自启                开 / 关
  安装驱动（首次使用）     自动安装没有完成时，用这一项重试
  设备名称：…             iPhone 列表里显示的名字，立即生效
  清理通知注册信息         删掉开始菜单快捷方式和 dropbridge:// 协议注册
  蓝牙 beacon             用电脑自带的蓝牙帮 iPhone 发现这台电脑（默认开）
  为实况图生成单图副本     收到实况照片时多存一张 xxx-still.jpg（默认开）
  重新启动后端 / 重置链路  手机看不到电脑或传输卡住时用
  退出

数据放在哪
  程序自己的数据都在本文件夹的 data\ 里：
    data\settings.ini  设备名、接收文件夹、各项开关（纯文本，可以手改）
    data\keys\         TLS 自签证书和 AirDrop 实例 ID（升级时请保留，否则
                       手机列表里会多出一个 DropBridge）
    data\received\     收到的文件（除非你改了接收文件夹）
    data\logs\         各进程日志
  另外，下面这些内容会写到系统里（都只针对当前用户，驱动除外）：
    - 开机自启项（HKCU ...\CurrentVersion\Run）
    - 通知按钮需要的开始菜单快捷方式 DropBridge.lnk、dropbridge:// 协议和
      通知身份（HKCU\Software\Classes）
    - 驱动安装：WinUSB 驱动包（pnputil），以及给它签名用的自签证书
      （导入到本机的「受信任的根证书」和「受信任的发布者」）

升级
  覆盖 DropBridge.exe 和 backend\，保留 data\。

卸载
  1. 在托盘菜单里关掉「开机自启」，点「清理通知注册信息」，然后退出。
  2. 删除整个文件夹。
  3. 想让网卡换回原厂驱动，按 setup\README.txt 里「怎么恢复原驱动」操作。

已知限制（重要）
  - 这是内部测试版，没有代码签名，Windows SmartScreen 可能会弹警告。
  - radio 组件静态链接了 Realtek 固件，在固件再分发许可解决之前只能内部测试。
  - 只能接收（iPhone → 电脑）。从电脑发给 iPhone 已确认无法实现。
  - 实测速度约 1.1 MB/s（29 MB 视频约 27 秒，信道 149、20 MHz），但波动较大。
  - 已知问题：第一次传完以后，手机偶尔会看不到电脑，这时用「重新启动后端」
    就能恢复；两台 iPhone 同时打开隔空投送时，速度会明显变慢。
  - 网卡要注意散热和 USB 供电。

故障排查
  - 手机看不到 DropBridge：先确认托盘状态为就绪；还不行就点
    「重新启动后端」。日志在 data\logs\<会话>\awdld.log，
    里面应该能看到 peers 1。
  - 托盘提示「网卡没响应，请拔插」：拔下网卡再插回，然后点「重新启动后端」。
  - 想用控制台方式调试：tools\Start-Chain.ps1。它默认只打印将要执行的命令
    （dry-run），加 -Run 才会真正初始化网卡。
