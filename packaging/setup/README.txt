首次使用：把网卡的 Wi-Fi 接口绑定到 WinUSB
==========================================

每台电脑只做一次。做完之后就不用再管了，除非你换 USB 口/换电脑。

为什么要做
----------
这个程序绕开 Windows 自带驱动，直接用 libusb 跟 RTL8821CU 网卡说话，才能收发
AWDL（隔空投送）帧。Windows 默认给这个网卡的 Wi-Fi 接口装的是 Realtek 网络驱动，
libusb 打不开它，所以第一次要先换成 WinUSB 驱动。

⚠️ 只换一个接口
---------------
你的网卡是一个"复合设备"，有三个接口：

  MI_00   蓝牙            ← 绝对不要动（这个程序不用它）
  MI_01   厂商预留        ← 不要动
  MI_02   Wi-Fi           ← **只换这一个**

下面给的步骤里，唯一要选中的就是 MI_02。

操作步骤
--------
1. 先**拔掉再插上**网卡（直插机箱后面板，别用前面板或 USB hub）。
2. 双击本文件夹里的 `Bind-WinUSB.cmd`，按提示允许管理员权限。
   - 如果它说"已经绑好了"，就不用往下做了，直接双击外面的 `DropBridge.exe`。
3. 脚本会打开 Zadig。在 Zadig 里：
   a) 菜单 `Options` → 勾上 `List All Devices`；
   b) 上方下拉框里找 **`RTL8821CU` / `802.11ac NIC`** 这一项（它的 USB ID 是
      `0BDA C820`，接口 `MI_02`）；
      **不要选** `USB Composite Device`，**不要选**带 `Bluetooth` 字样的项；
   c) 右边目标驱动确认是 **`WinUSB`**（不是 libusb-win32，也不是 libusbK）；
   d) 点 **`Replace Driver`**，等它完成（1–2 分钟，中途别拔网卡）。
4. 回到脚本窗口按回车，它会复查结果：
   - 显示 `OK: MI_02 已绑定 WinUSB` → 成功，双击外面的 `DropBridge.exe` 开始用；
   - 显示 `失败` → 重新插拔网卡再跑一次脚本；仍然失败请把窗口里的文字发给我。

怎么恢复（后悔药）
------------------
想退回 Realtek 原驱动：设备管理器 → 找到 `RTL8821CU`/`802.11ac NIC` →
右键 → 卸载设备 → 勾"删除此设备的驱动程序软件" → 确定 → 拔插网卡 →
Windows 会自动装回 Realtek 网络驱动。之后 Wi-Fi 恢复正常，DropBridge 就不能用了。

关于 Zadig
----------
`zadig-2.9.exe` 是第三方工具（作者 Pete Batard，GPLv3），我们只是把它放进包里
方便你一次完成驱动替换。许可证全文见 `licenses\zadig-GPL-3.0.txt`。
Zadig 能替换任意 USB 设备的驱动，**请不要用它动别的设备**（键盘、鼠标、U 盘、
摄像头），否则那个设备会坏掉，只能用设备管理器卸载恢复。
