Why it is here: Windows ships a Realtek network driver for the RTL8821CU Wi-Fi
interface (USB\VID_0BDA&PID_C820&MI_02). DropBridge talks to that interface
through libusb, which needs the interface bound to WinUSB instead. Zadig does
that binding once per machine, from `Bind-WinUSB.cmd`.

source for Zadig 2.9 and libwdi is available from the upstream locations above,
and on request from the distributor of this package for three years from the
date it was conveyed. This package does not modify Zadig.
